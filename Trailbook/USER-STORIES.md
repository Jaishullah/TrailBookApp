# Trailbook user stories

| # | User story | Acceptance criteria |
|---|---|---|
| 1 | As a new hiker, I want to register so that I can keep a personal trail collection. | Username, valid email and a password of at least eight characters create a local account. Invalid or duplicate entries show feedback. |
| 2 | As a returning hiker, I want to log in so that I can access my saved trails. | Valid credentials open Explore. Invalid credentials show an error. |
| 3 | As a hiker exploring Yosemite, I want to browse trails so that I can choose a route. | The home screen displays the Trailbook logo, a featured trail and a trail directory. |
| 4 | As a hiker choosing a route, I want to open trail details so that I can check its distance, difficulty and estimated time. | A directory arrow opens the corresponding detail screen. |
| 5 | As a hiker planning ahead, I want to save trails so that I can find them again after reopening the app. | Save and remove actions update the Saved trails screen and persist per account after reload. |
| 6 | As a hiker planning an outing, I want to check current conditions so that I know what to expect. | The weather screen fetches temperature, wind and humidity for the selected trail and offers a retry on failure. |
| 7 | As an account holder, I want a settings menu so that I can find preferences, notifications, saved trails and logout. | The header gear opens a menu with working destinations and logout. |
| 8 | As a hiker who uses miles, I want to change distance units so that trail details use my preferred measurements. | The selected unit persists and changes distances on the detail screen. |
| 9 | As a hiker configuring alerts, I want to enable and test notifications so that I can confirm the setup works. | The alert setting persists. An enabled test produces an in-app alert and also requests a desktop notification on supported browsers. |
